# 🏙️ Metropolis

**Metropolis** is a scalable, open multi-vendor e-commerce platform—think of it as a foundation for building your own version of Amazon, Alibaba, or Etsy. It supports multiple vendors, dynamic product listings, order management, and a modular plugin architecture.

---

## 🚀 Features

- 🛒 Multi-vendor marketplace system
- 📦 Product listings, search, and categories
- 🧾 Order and payment management
- 🧑‍💼 Vendor registration and dashboards
- 📈 Analytics and reporting tools
- 🌐 API-first architecture (REST)
- 🧩 Modular and extensible

---

## 🧰 Tech Stack

- **Frontend**: ReactJS
- **Backend**: C#.NET
- **Database**: PostgreSQL

---

## 🛠️ Getting Started

Clone the project:

```bash
git clone https://github.com/aubriaco/metropolis.git
cd metropolis
```

Install react dependencies:

```bash
cd Marketplace/react-src
npm install
```

Start the frontend dev server:

```bash
npm start
```

Start the backend:

```bash
cd Marketplace
dotnet run
```
